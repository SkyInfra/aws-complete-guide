Deploy this app to EKS

Replace the values in angle brackets with your own. The project's README has the same steps.

  1. Build the image and push it to ECR

    On an Apple Silicon Mac, add --platform linux/amd64 to the build command so the image runs on x86 nodes.

    aws ecr create-repository --repository-name eks-demo --region <region>
aws ecr get-login-password --region <region> | docker login --username AWS --password-stdin <account-id>.dkr.ecr.<region>.amazonaws.com
docker build -t eks-demo .
docker tag eks-demo:latest <account-id>.dkr.ecr.<region>.amazonaws.com/eks-demo:latest
docker push <account-id>.dkr.ecr.<region>.amazonaws.com/eks-demo:latest

  2. Create the cluster

    This takes 15 to 20 minutes, and the cluster costs money for as long as it exists.

    eksctl create cluster --name eks-demo --region <region> --nodes 2 --node-type t3.small

  3. Point the manifest at your image and apply it

    Edit the image: and AWS_REGION lines in k8s/deployment.yaml first.

    kubectl apply -f k8s/

  4. Find the address

    Wait until the service shows an address under EXTERNAL-IP, then open it in your browser.

    kubectl get pods -n eks-demo
kubectl get svc eks-demo -n eks-demo

  5. Watch the load balancer spread requests

    Each curl opens a new connection, so you should see different pod names.

    for i in $(seq 1 12); do curl -s http://<load-balancer-address>/api/whoami | grep -o '"pod":"[^"]*"'; done

  6. Clean up when you are done

    Delete the app first so AWS removes the load balancer, then delete the cluster.

    kubectl delete -f k8s/
eksctl delete cluster --name eks-demo --region <region>
