Run the same steps yourself

Replace the values in angle brackets with your own AWS details.

  1. Build the image
    docker build -t ecs-demo .
  2. Test it locally
    docker run --rm -p 8080:80 ecs-demo
  3. Log in to ECR
    aws ecr get-login-password --region <region> | docker login --username AWS --password-stdin <account-id>.dkr.ecr.<region>.amazonaws.com
  4. Tag and push the image
    docker tag ecs-demo:latest <account-id>.dkr.ecr.<region>.amazonaws.com/ecs-demo:latest && docker push <account-id>.dkr.ecr.<region>.amazonaws.com/ecs-demo:latest
  5. Roll out to ECS
    aws ecs update-service --cluster <cluster> --service <service> --force-new-deployment
